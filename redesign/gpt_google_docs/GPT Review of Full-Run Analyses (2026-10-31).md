# GPT Review of Full-Run Analyses (2026-10-31)

# Decision

The full-run records establish substantial predictive information in the relations among three messages, but substantially weaker recoverability of whether a single final message came from a hub or a diamond. The main text-only findings are computed on held-out worlds and do not use the proposition judge. Nevertheless the analysis is not yet publication-ready as written. Several reported tests address a different null from the one named, a directional set feature violates the stated order-invariance requirement, some planned analyses are incomplete, and the anchored account has measurement and null-construction limitations that human coding alone will not repair. These are analysis/instrument repairs, not grounds for another producer run or a redesign.

Disposition: retain the generated corpus and the main text-only out-of-fold predictions. Correct and rerun the affected set-feature analyses, replace the primary inferential summary with a transparently qualified comparison of the planned conditional bootstrap and refitted permutation tests, complete the missing planned comparisons, and validate the proposition judge before reporting anchored conclusions. Do not interpret the direct-report negative-control discrepancy as evidence that unused branches transmitted information.

# Sources and scope

This review uses the October 31 brief, text\_only.md, secondary.md, anchored.md, the five named analysis scripts, residue/judge\_matcher.py, residue/analysis.py, residue/features.py, residue/readers.py, the build README, and Parts V, V-A, VI and VIII of the v8 design. The analysis files are outcomes of the stored full run, not independent replications. The full run reports 32,974 producer calls, 13,139 of 13,140 planned conditions realized, one Haiku terminal failure, and 5,040 valid reader calls. The main analyses use 60 research worlds with three replicates, world-grouped outer five-fold evaluation, and inner world-grouped penalty selection. Verification worlds remain outside those analyses.

# I. Result-by-result assessment of assembly, labels, folds, statistics, and scope

P1, direct report and single-relay negative controls. The code assembles D0 against NC0 and R1 against NCR1, with a world-and-replicate-matched terminal for each structure. The intended parentage labels and world grouping are appropriate. Features AUCs are 0.491 for direct report versus dead-end control and 0.510 for one-relay chain versus its dead-end control. Embedding AUCs are 0.553 and 0.501. The stipulated 0.43–0.57 equivalence band with two-sided 90% fixed-prediction bootstrap intervals yields three equivalence classifications and one inconclusive direct-report embedding result, not four passes. The direct-report embedding score exceeds all fifty refitted label permutations, with Monte Carlo p \= 1/51 \= 0.0196. This does not demonstrate a causal influence of an unused branch. The two terminal requests are identical apart from the logical call/seed and execution context, so any consistent discrimination is a nuisance difference or statistical fluctuation under an exchangeability test. The control therefore warns against unqualified structural interpretations of small AUC excesses.

P2, single-message hub versus diamond. The comparison correctly contrasts the full-access hub (SI-same: three independently sampled observations, each relayed) with the diamond (SD-same: one observation fanned out to three relays), both synthesized, with matched depth and shared full-world access. The feature learner gives AUC 0.552 (conditional bootstrap interval 0.509–0.596); the embedding learner gives 0.515 (0.482–0.546). The fixed-prediction centered bootstrap reports one-sided p \= 0.010 for features. The refitted paired-label permutation gives observed 0.5519, two-sided p \= 0.1373 and, when the design's one-sided alternative is used, p \= 0.0784 (three of fifty null values at or above the observed value, plus-one rule). Thus neither the two-sided nor the one-sided permutation rejects at 0.05. The report should not carry forward “P2 rejects chance” from the bootstrap-based Holm table as though it were sustained by the later inference. The contrast remains a small positive out-of-fold ranking result, with uncertainty about retraining and a negative-control discrepancy.

P3, three unconnected sources versus out-star. The assembly correctly selects full-access, neutral Study 2 sets from the primary producer, compares the pooled formal/attributional baseline with that baseline plus pairwise lexical and semantic features, and groups the 360 sets by world. Reported AUC is 0.699 for pooled features and 0.859 with relational features, a gain of 0.160 (conditional paired bootstrap 0.114–0.202). This comparison is the strongest text-only evidence that relationships among observed messages contain information not summarized by pooled single-message descriptors. However, the relation extractor's sentence-order statistic is directional (Section II), so the current AUC is not yet an estimate for the order-invariant set model specified in the design. More importantly, the secondary permutation table tests pooled and pairwise AUC against an exchangeability null separately. It does not construct the null distribution of A\_r − A\_0. The reported p \= 0.032 for each model is not a permutation p-value for the incremental gain. The fixed-prediction paired bootstrap is an appropriate \*conditional\* estimate for the design's stated fitted-model estimand, while a refitting analysis of the gain would be a separate stress test. Rerun P3 after symmetrizing the relation feature, then report the paired gain and its actual uncertainty.

Secondary chain depth and split-input hub. Multiclass grouped out-of-fold macro AUCs are 0.599 (features) / 0.613 (embeddings) for chains of one, three or five relays, and 0.613 / 0.630 for hubs with one, two or three split-access spokes. These labels and grouped folds match the conditions. The observed differences support modest within-corpus classification, not exact recovery of the number of processing stages or spokes in individual reports. In the secondary permutation table, these scores exceed all thirty null replicates, so the reported p \= 0.032 is a resolution limit, not evidence of a precisely estimated tail probability. Accuracy and macro-F1 are reported, but per-class errors and event-type results are needed to interpret specific histories.

Access, downstream and composition contrasts. The diamond versus overlapping-access hub AUC is 0.555 using formal/attributional features and 0.609 using embeddings. It is a total contrast involving different observation access as well as independence, not the same estimand as P2. After one downstream relay, hub/diamond AUC falls to 0.546 / 0.519, and after three it is 0.542 / 0.506. These are descriptively near chance, although claiming a rate of decline requires paired differences and intervals on those differences. The composition analysis includes only chain of five relays against diamond followed by three relays (0.489 / 0.456). The v8 plan also calls for chain of five versus hub followed by three relays and a three-class composition problem among all three, which are absent from analyze.py and the reported secondary analyses. Implement these two analyses from already-generated terminals, with the same folds and learner. No new model calls are required.

H6 transfer. Direct model-conditional comparisons of the hub/diamond contrast under other producer environments and news genre are correctly separated from causal effects of any specific model-family attribute. The feature AUCs are 0.552 for Gemini, 0.573 for Haiku, 0.513 for Luna, and 0.540 for news. Transfer performance is lower: A to B family 0.529, Gemini to Haiku 0.499, incident to news 0.509. The chain comparison (one against three relays) is more robust within producer, with AUCs 0.620, 0.563, 0.626 across producers and 0.653 for news; transferred AUCs include 0.617 family, 0.548 producer, and 0.596 genre. Code uses a fixed C \= 1 for transfer, not the inner-selected model, and same-setting and transferred test rows need not be exactly the same world–replicate observations, despite the design's phrasing “on the same test worlds.” Label these descriptive domain-transfer estimates, not paired estimates of an AUC loss; report the actual test-world and replicate intersections. No world-id leak was found in the feature matrices.

H7, one-message leakage in sets. analyze.py selects a single terminal at random for each full/partial and neutral/conceal/stripped set, using a fixed seed, then applies world-grouped classification and the stipulated three-way tolerance rule. This matches the broad check. Some full-neutral and partial-neutral pairs remain inconclusive rather than equivalent, and several AUCs fall below 0.43 without having an interval entirely below the lower limit. The planned results by prompt family and worst stratum are not present. The neutral and stripped text-only formal features are effectively identical except for a Sources-line presence indicator that is constant within each arm. Thus their repeated AUCs are expected, not an independent robustness replication. The check does not establish that a single message contains no structural clues in every stratum.

H8/H9 set structures and pair labels. The three-class macro-AUC analysis includes three unconnected sources, out-star and Y, with primary-producer pooled 0.605, pairwise 0.772, and aggregate of independent single-message predictions 0.515. The analogous pairwise scores for Haiku and Luna are 0.861 and 0.860. The shared-root pair classifier reports AUC 0.803 on full access and 0.949 on partial access. These are reported on world-grouped predictions and are meaningful as predictive diagnostics. But the pairwise shared-root labels for Y assume the first two messages are the related pair in \*generation-slot order\* (the actual graph is generated that way). The set reader independently randomizes presentation and remaps the odd-message label. A set-level predictor intended to be permutation-invariant must randomize or symmetrize pair presentation together with its labels. The directional order-similarity feature makes the current pair classifier sensitive to which of two texts is listed first. The partial-access advantage is explicitly a joint effect of access packages and ancestry, not evidence that ancestry alone becomes almost perfectly readable.

H10 attribution. The paired reader contrasts use the same first-replicate worlds and normalize IND versus out-star probabilities from each reader's five-configuration distribution. This is coherent, and the five-to-three structure mapping and pairwise marginal formulas in readers.py are correct. Full-access removal of the final Sources line has an inconclusive effect on both readers: \+0.017 for Sonnet and −0.029 for Terra, with 90% intervals crossing the equivalence bounds. Under partial access the changes are approximately zero. Generative concealment versus deterministic stripping is a different treatment that can alter discourse content, and full-access changes (+0.058 and \+0.072) must not be attributed to attribution-line loss alone. For the text-only pairwise classifier, unchanged stripped-versus-neutral predictions largely follow its extraction rule: all relational features drop the Sources line before comparing messages, and remaining source-line presence is constant within each arm. Its exact zero AUC difference is not a general proof that attribution carries no information.

Prompted readers. The set readers output five configuration probabilities and derive the three shape probabilities by summation, which is coherent. Their high partial-access AUCs (near 1 for both readers) are compatible with package overlap being a strong cue. Reader performance is descriptive because examples, supervision, and inputs differ from the feature classifiers. All replies parsed, but this is compliance with output schema, not independent validation of ancestry inference. The report's “Items 180” for three-class set tasks is a count of evaluated sets, not 180 independent worlds. Reader example selection from training worlds is a correct safeguard, conditional on the logged fold assignment.

Part V-A structure predictor. The thirteen-history multinomial feature model is trained with world-grouped folds. Its class probabilities are used consistently to derive synthesis, fan-in, root-count and rewrite-count marginals. The reported macro AUC 0.627 and accuracy 0.218 show nonchance discrimination but poor specific-history recovery. “Chance 0.077” is only the uniform 1/13 baseline. The empirical majority-class baseline is 360/2,880 \= 0.125, because D0/NC0, R1/NCR1 and SI-same/SI-div represent duplicate conditions under their respective history labels. Several classes receive almost no hard predictions in the confusion matrix, and some are never selected. The promised embedding and boosted history predictors, inner-selected best-model comparison, Brier score, event-type/producer/genre analyses, and separate attribute-model check are absent. The five-configuration \*set predictor\* and its same-root marginals are also not reported as an integrated predictor, though the prompted-reader five-way interface exists. The current result is a feature-only partial implementation of Part V-A, not the complete specified prediction system. Do not describe the reported 0.218 accuracy as a final answer to the broader structure-recovery question.

General assembly and fold integrity. analyze.load() reconstructs trials from the append-only store using realized graphs, sorts rows by world, replicate, genre, producer and condition, and uses the fixed 60-world fold map. Nested L2 penalty selection does not fit text features on test labels, and supervised standardization happens within training pipelines. One Haiku trial failure is disclosed. Set rarity tables are built on outer training worlds for the target outer fold. There is a narrower inner-CV issue: rare-ngram definitions are computed from the entire outer-training sample, including an inner validation fold used for penalty selection. This is an unsupervised transformation leak into the inner validation step, although it does not use the held-out outer world's text for the final outer-fold prediction. Refit rarity tables inside inner folds for a fully nested procedure, or describe this as an inner-model-selection approximation. More consequential for H8 is the directional feature error described below.

# II. Specific coding and statistical corrections

Set permutation invariance is broken in one feature. In residue/features.py, pair\_features(a,b) computes \_order\_similarity(sentences(a),sentences(b)). That function maps each sentence of a to its best matching sentence in b and counts nondecreasing positions. The reversed computation maps sentences of b to a instead and need not have the same value. Embedding cosine and rare-ngram Jaccard are symmetric, but order similarity is not. Consequently f\_set\_relational's min, median and max over unordered message pairs can change when a, b and c are reordered. The interface promises order-invariant set features, and the set reader randomizes message order. This is an actual feature-definition error, not merely a robustness limitation.

Exact minimal repair: in pair\_features replace the current sentence-order value with 0.5 \* (\_order\_similarity(sa, sb, embed) \+ \_order\_similarity(sb, sa, embed)). Leave the other two pair features as specified. Add a unit test that all six permutations of three fixed messages produce identical f\_set\_relational vectors (to a numerical tolerance), and that pair\_features(a,b) equals pair\_features(b,a). Recompute P3, the three-structure set results, H9 pairwise same-root scores and any H8 text-relational benchmarks. For the pairwise root classifier, permute the three messages within each set and carry the true same-root labels through the same permutation, or demonstrate exact pair-feature invariance before interpretation. Stored messages are sufficient.

P3 gain inference is not the reported permutation test. In analyze\_secondary.py, P3\_perm calls perm\_null separately on X0 and on the pairwise probability function. Thus its two p-values test no association between structural labels and each model's predictors. They are not a test that the extra relational feature block improves predictive AUC above the pooled baseline. A correct \*gain\* resampling procedure must compute Δ \= AUC(pairwise) − AUC(pooled) inside every resample, preserving pairing of the two predictions on the same held-out worlds. The planned paired fixed-prediction world bootstrap already does precisely that for the conditional OOF estimand. If the aim is an additional refitted uncertainty analysis, resample worlds, refit and retune both learners on resampled training worlds, evaluate them on held-out worlds under the same fold rule, and calculate their paired gain. Repeating independent label permutations of both models is not an incremental-value null when the pooled model itself predicts structure. Report the old separate-model permutations only as tests of overall structural association. The P3 bootstrap p of 0.0000 means no event in 2,000 draws, not a literal probability zero. Give it as p \< 0.0005, conditional on fixed OOF predictions.

The Monte Carlo permutation count is too small for tight primary inference. Fifty permutations give 0.0196 as the smallest achievable two-sided or one-sided plus-one p, and thirty give 0.0323. In particular, for P2 the observed feature AUC of 0.5519 exceeds 3/50 of the simulated null scores, giving one-sided p \= 4/51 \= 0.0784, while the report quotes two-sided 7/51 \= 0.1373. The design's primary P2 test is one-sided, so give both if desired but do not substitute a two-sided result without explanation. Run at least several hundred, preferably 999 or more, paired permutations on the corrected final features for a stable p and the Holm comparison. Call them label-exchangeability permutations, not an exact randomized-treatment null: each structure was built from its own graph and seed, and outputs were not randomly relabeled by the experiment.

AUC orientation requires care. For a binary contrast, AUC below 0.5 is not automatically “no information.” It can mean a systematically reversed learned ranking, particularly where class orientation is fixed and retraining does not flip scores. Scores such as 0.419 for one H7 contrast or 0.456 for a composition contrast should be described as directional ranking scores with intervals. A classifier whose scores are intentionally inverted would have the complementary ranking. Keep the predeclared orientation and do not choose signs after seeing results.

Statistical scope of the conditional bootstrap. Part VIII explicitly defines the estimand as held-out performance of the fitted procedure on this fixed fold assignment and states that the world bootstrap keeps all out-of-fold predictions fixed, excluding retraining on newly sampled worlds. It is therefore incorrect to label the bootstrap a coding error merely because a refitted permutation distribution is wider. The bootstrap quantifies variation among held-out worlds, conditional on the fitted fold models. It does not represent the additional variability of fitting new models on new training worlds, nor does it fully account for the cross-fold dependence arising because one evaluation world's data contribute to other folds' training. The permutation instead asks a different label-exchangeability question after full retraining. It may be better calibrated for a claim of reproducible predictive learning, but it does not estimate the same interval. Keep conditional bootstrap intervals as \*descriptive intervals for the prespecified conditional estimand\*. Do not retain the original bootstrap-only rejection of P2 as the primary inferential conclusion, given this contradictory diagnostic. For primary inference on whether fitted learning reliably finds a small structural signal, use a fully refitted paired test on the final code and report both inferential views with their different targets. Treat this as a transparent post-verification departure from the original design. The existing P3 result remains a positive descriptive gain pending feature correction and its appropriate paired refitted check.

Multiple testing and Holm. The existing Holm table adjusts the original bootstrap p-values for P2 and P3. It cannot simply be reused if P2 is replaced by a permutation p and P3 by an unrelated separate-model permutation p. Recompute the Holm family with p-values testing the \*specified\* alternatives: P2 AUC \> 0.5 and P3 ΔAUC \> 0\. The exact tests and their one-sided directions must be reported together. The negative control P1 is not in the Holm family, but its signal qualifies interpretation of P2 and single-message analyses rather than being ignored because it was originally conceived as an equivalence check.

P3 and H8 are not interchangeable. The primary P3 estimate is binary IND versus DEP and tests the marginal value of message-to-message relations. The three-class macro AUC for IND, DEP and Y is a separate target, as is pairwise same-root classification. The current secondary report generally keeps these distinct. Maintain that separation when presenting evidence, especially the near-perfect partial-access scores: under partial access, shared input packages can themselves make texts similar, so the result is not an estimate of ancestral dependence under otherwise equal information access.

# III. The dead-end-control difference: assessment and discriminating tests

The direct report and direct report with unused branches have the same relevant report-generation prompt, parent material and model settings, but separate call keys and seeds. The dead-end observations cannot alter the direct report through a stateless API. Hence a reproducible classifier difference cannot be interpreted as transmission along nonexistent edges. It can arise from key-derived seed effects, call position relative to provider model/load changes, differences in retry histories or accepted-output selection, an unnoticed prompt/parameter mismatch, or ordinary sampling variation amplified by a flexible embedding classifier. The request-hash audit narrows the prompt hypothesis, but the generation-time and seed distributions still need to be checked on the actual paired records.

The proposed order diagnostic is not decisive as stated. It found embedding AUC 0.487 with p \= 0.839 for identifying the earlier versus later half among 1,080 nominally identical requests. However the formal-feature learner achieved AUC 0.533 with one-sided Monte Carlo p \= 0.032 from 30 permutations. The README's assertion that generation order “found nothing” therefore discards a positive result from the second learner. Moreover, early/late-half classification across six calls per block is not the same as the D0/NC0 time contrast: NC0's call was later in 164/180 pairs with a median 29-second gap. A pooled early/late test can miss a first-versus-specific-following-call effect, a short-lived model-load difference, or a seed-assignment effect.

Cheap discriminating analysis using existing records: first check byte-identical request body AND request settings, model version, finish reason, retry/acceptance status, seed and exact generation time for each D0/NC0 pair. Compute the gap and call-order rank and tabulate them by world and replicate. Then compare direct reports against other same-prompt observations within the same block, stratifying by rank and seed characteristics; fit a grouped classifier on rank-matched contrasts or adjust the held-out predictions for recorded timing and output length, with the same world folds. Generate pseudo-control labels among other same-request calls to test whether an embedding learner tends to separate any selected early observation from a selected later one. If seed is supported by the Google API, verify how it is forwarded and whether its distribution differs systematically between condition keys. None of these tests requires another model call. If the pattern remains unexplained and consequential, perform a small, separate randomized-order and seed-swap repeat on reserved worlds, with new call identities and archived prompts, to distinguish seed from execution order without contaminating the full corpus.

Implication: P1 does not support universal inertness in the single-message embedding view. This limits claims that small text differences uniquely reveal ancestry. It does not logically erase P3 because P3 compares relational versus pooled information from the SAME message sets, and the negative-control anomaly concerns independently realized reports. Still, the anomaly raises a general concern that generation context may leave systematic traces, so the pairwise results should be checked for residual production-order sensitivity. P2's feature AUC 0.552 is similar in magnitude to the anomalous negative-control AUC, making a strong hub-versus-diamond structural claim particularly unwarranted.

# IV. Proposition judge and the anchored shared-deviation analysis

Instrument design. The new gpt-6.1-terra judge reads a world record's twenty proposition texts, the two disputed pairs, and one message body. It does not see condition labels, network shape, other messages, or the final Sources line. This is a defensible blinded measurement arrangement for content matching, and it avoids the embedding matcher's demonstrated failures on paraphrase. Its four states map onto the design's preserved, altered, qualified and omitted categories as stated, changed, doubted and absent. The dispute outputs first, second, both and neither are also conceptually appropriate. The machine-readable parser checks that all IDs have allowed values and preserves the archived model reply, but validity of JSON does not establish semantic agreement. Judgments for 2,662 unique primary-producer messages should be described as instrument-generated measurements, not ground truth.

State-definition ambiguity. “Changed” currently says that the report states the fact but with a different detail that contradicts the record. When a report contains a contrary claim rather than a paraphrase of the same one, an annotator might mark the original proposition absent, or mark it changed, or mark the opposing dispute member stated. “Doubted” can be triggered by “said,” “according to,” or explicit mention of disagreement, even when source attribution is part of the original world record. These boundaries especially affect disputed facts. Introduce a fixed precedence rule in the judge and the human-coding rubric: a positive assertion of an equivalent proposition is stated even if paraphrased; explicit added epistemic doubt without contradictory detail is doubted; a substantively different asserted value or role on the same referent is changed only when there is an identifiable reference to that underlying proposition; a proposition not recoverable from the message is absent. Record first/second/both/neither independently of those per-fact states, but require consistency: “both” must have both claim contents recoverable, and “first”/“second” must not be assigned when neither claim is actually asserted. One message may express a qualified one-sided position, which the rubric must address without treating the mere mention of an alternative as acceptance of it. The output parser currently does not enforce any such cross-field consistency.

Limited substantive coverage of the advertised full feature family. The current prop\_feats adds counts of absent, changed and doubted facts plus counts of first, second, both and neither resolutions. It does not count unsupported additions or proposition order, both named as propositional features in Part VI. Therefore the comparison called “full specification” in anchored.md is not literally the complete designed propositional specification. Either implement and validate unsupported-addition and order features uniformly, or rename it “text plus seven judged state/resolution counts,” explain the omissions, and avoid treating the current incremental AUC as a complete test of the propositional family.

Deviation-event rule. analyze\_anchored.py correctly avoids counting both dispute members separately when a pair has its own resolution. For nondisputed propositions it creates events (state, proposition ID) for absent, changed and doubted. For a disputed pair it creates (dispute, pair ID, first/second/neither), with “both” designated faithful to the conflicting record. This representation is coherent as a compact \*difference from the complete world record\*. But “neither” is not evidence that a distinctive error propagated: two independent 200-word reports can both omit a dispute because it is peripheral or space is limited. Similarly, independently omitted nondisputed facts produce matching absent events when both authors compress the same world. Include separate ablations for shared altered/doubted propositions and affirmative one-sided conflict choices, for omission-only events, and for disputed “neither” events. A positive result driven only by shared absence should be labeled common selection/compression rather than inherited innovation.

A more consequential partial-access error is in the event denominator. events(result, world) considers all twenty propositions regardless of what the observer was assigned. In the partial-access arm, an observer cannot state propositions that never entered its package. Those should not be counted as message-level deviations from supplied information, and two related messages may share \*structural nonaccess\* by design. Current partial-access H8 therefore conflates unavailable information, actual inherited omission and the common-package structure. The near-perfect partial-access anchored AUC of 1.000 and the fraction of 1.16 are not evidence of a strong inherited-deviation mechanism. Exact repair: for each message derive the union of propositions that could reach it from its actual observation ancestors, retain a nondisputed absent/changed/doubted event only for propositions in that accessible set, and define a pairwise shared-deviation opportunity over propositions accessible to BOTH messages. Handle a disputed pair only when the relevant claims could actually have reached each message, or separate one-member exposures with an explicit rule. Recalculate partial-access H8, retaining the original all-world calculation only as a \*total access-plus-ancestry\* descriptive contrast. For the primary full-access P3 and its anchored follow-up this nonaccess problem does not arise.

The full-access null is currently an intercept shift, not a substantive model of coincident deviations. For each outer fold, analyze\_anchored.py computes the average intersection count across independent, full-access sets from training worlds, μ\_f. Then it subtracts the same μ\_f from each of the minimum, median and maximum pair-intersection counts of every row being analyzed for that outer fold. Because the logistic learner includes standardization and an intercept, subtracting the same constant from every row leaves its predictions invariant, up to numerical error. The adjustment therefore does NOT remove world-specific or proposition-specific expected overlap due to salience, report length, or propensity to omit certain claims. It does satisfy the literal instruction to subtract a training-world full-access IND expectation, but operationally it does not distinguish an unusually shared inherited deviation from two independent writers independently dropping the same conventional detail.

A discriminating check can use the \*training\* independent full-access sets to estimate expected shared events conditional on event identity or proposition class and the two reports' opportunities to include them, then form excess events relative to that matched expectation without touching held-out labels. At minimum, tabulate observed versus expected counts by event type, omission/nonomission category and report length, and compare the same model with and without the “neither” and absent-event indicators. Even a simpler leave-one-world-out within-training null that varies by proposition position, dispute kind, or accessible information is more informative than a common intercept shift. This is an instrument/analysis repair to the existing H8 question, not a new structural treatment. A model using world-anchored proposition identities is a diagnostic of what carried the signal and must not be recast as a deployable text-only predictor.

The contribution fraction is not a causal proportion. The full-access result A\_0 \= 0.699, A\_s \= 0.814 and A\_r \= 0.859 gives (0.814 − 0.699)/(0.859 − 0.699) ≈ 0.72. It indicates how large the \*incremental ranking improvement\* from one particular anchored feature block is relative to the improvement from the registered text-relational block, conditional on these classifiers. It does not show that 72% of the causal effect or of the learned signal is transmitted by inherited deviations. This is especially clear under partial access, where A\_s exceeds A\_r and the ratio is 1.16. Such ratios need not be bounded by one. Fixed-OOF bootstrap intervals also exclude retraining variability and inherit all judge misclassification. Keep the fraction as a descriptively defined AUC-gain ratio with its scope and denominator, not an “explained variance” or mediation fraction.

Human validation of the new judge. The v8 validation plan applies to the \*instrument actually used\*, not only to the retired embedding matcher. Use 240 messages from the reserved verification run under the final generation and validation rules, stratified across Study 1/Study 2, node function, structural group and producer. A blinded human codes each of the twenty proposition states and the two dispute resolutions against the world record. A second independent, design-uninvolved coder double-codes 60\. Report pre-adjudication kappa by judgment, confusion matrices, class frequencies and intervals, then adjudicate under a written rubric. Map the human categories preserved, altered, qualified and omitted explicitly to the judge's stated, changed, doubted and absent, and retain first/second/both/neither as four distinct resolution classes. Each natural-sample judgment must reach pooled class-balanced accuracy at least 0.80. A class with fewer than 30 natural instances is not validated for that class and dependent conclusions are withheld.

The challenge set must include at least forty controlled instances of every state and dispute class for EACH node function and producer, with per-class recall at least 0.85 and false-change rate under 0.10 for meaning-preserving hard negatives. Existing deletion, number/time/entity replacement, dispute-switch, reordered-clause and number-word edits should be retained. Add adversarial cases aimed at the judge rather than the embedding matcher: paraphrased multi-clause facts; one reversed “A before B” sequence; statements containing both competing numeric values with attribution; the same value mentioned as a different event's time; one member named without asserting it; one-sided hedged assertions; and a contradiction accompanied by accurate unrelated numbers. Include explicit tests that per-fact state and dispute resolution agree, and the twelve stripped/unstripped pairs that should be identical because the judge reads bodies. Compute agreement and error rates by producer, node function, world, dispute kind and whether a proposition was actually accessible. These are necessary because systematic judgment errors on similar messages can create spurious shared events in the same way as genuinely inherited mistakes. Do not select or edit validation examples using the judge's own results.

Decision gate for anchored claims. The reported full-access shared-deviation counts (2.23 under independent sources versus 3.41 under out-star) and the A\_s gain 0.116 are interesting instrument-dependent summaries, not validated mechanistic evidence. Even after human agreement clears the specified thresholds, the null and shared-omission analyses above must be corrected before concluding that inherited deviations explain the relational prediction advantage. If either validation component fails, Part VI explicitly makes the text-only specification primary and withholds claims about inherited omissions, alterations and conflict resolution. The label “UNVALIDATED” in anchored.md is appropriate, but it is not sufficient to turn a misspecified event denominator or a constant-only null adjustment into a valid explanation.

# V. Statements supported now, and statements to withhold

Supported descriptive statements from the archived text-only analyses:

The three-message relations of full-access, neutral reports distinguish three unconnected sources from an out-star more effectively than the registered pooled formal/attributional features in the current implementation, AUC 0.859 versus 0.699, Δ \= 0.160. This result requires recalculation under the corrected order-invariant relation feature before it becomes the final P3 estimate. The broad conclusion that cross-message relations convey useful information is more secure than any specific p-value currently attached to it.

A single final report carries relatively weak information about whether it arose through the hub of three independent observations or through a diamond that fans one observation into three relays and then merges them. The feature AUC of 0.552 is positive but small, the embedding AUC is 0.515, and a refitted paired-label test does not reject chance at 0.05. The unsupported conclusion is “the hub is reliably distinguishable from the diamond on one message” under the stated primary inferential standard.

The linear chain of one, three and five relays and the hub with one, two and three split-access spokes leave moderately recoverable differences in final texts. These are secondary world-held-out classification results. They do not show that particular chains or spoke counts can be recovered accurately in most individual cases.

Among three-message configurations, the text-relational model yields macro AUCs around 0.77 for Gemini and 0.86 for the two other producer environments on full-access neutral sets. Pairwise same-root classification also works above chance in the current representation. Those values require the permutation-invariance correction before final reporting. Under partial access, very high classification performance is a joint consequence of package differences and shared ancestry, not an isolated ancestry effect.

The two prompted readers can recover a substantial amount about three-message configurations on full-access reports, and nearly perfectly distinguish many partial-access configurations. Their results are valid as performance of the \*specific example-prompted readers\*, not as evidence that any particular method family is superior. Comparisons with the trained feature classifiers are descriptive because the supervision and input contexts differ.

The thirteen-history single-message model yields macro AUC 0.627 and accuracy 0.218. It is better than the 0.125 empirical majority-class accuracy baseline but does not recover most precise histories. It is only the feature-learner implementation of the structure predictor. The set predictor's five-configuration interface, the alternative single-history learners, and the full planned output summaries remain to be completed.

The dead-end control of the direct report is unexpectedly separable with the embedding learner (AUC 0.553). That observation is supported as a \*control discrepancy\*. It does not identify influence from discarded branches and, because the same request content should produce distributions independent of unused graphs, it undermines strong causal attribution of small single-message classification signals without a generation-context check.

Statements not yet supported:

Do not claim that most of the relational prediction gain is \*caused by inherited deviations\*. The proposition judge has not passed the specified human validation, the deviation representation treats common nonmention as a matching event, the null adjustment is only a constant shift, and the partial-access variant counts unobserved propositions as omitted.

Do not claim the original Holm-adjusted rejection of hub-versus-diamond as a secure primary result. It uses the original conditional bootstrap p-value while the later refitted label analysis disagrees, and the final family must test the actual P3 gain on order-invariant features.

Do not claim robustness to arbitrary prompts, human communication, unseen provider/model generations, or source networks outside the finite set of one-way shapes and the two report genres. The evidence concerns the registered fictional-event bank, registered prompt pools, three producer environments, and fixed world-held-out folds.

Do not claim the full Part V-A prediction system or the full family of H12 composition contrasts has been implemented. Do not infer H11's unbuilt world-free accuracy or a causal mediation fraction from the anchored classifier comparison.

# VI. Minimum correction and release sequence

No additional producer calls are necessary for the corrections below. They use the stored full-run records, the same fold assignment, and, for anchored validation, the already reserved verification texts.

First, symmetrize sentence-order pair features, assert six-permutation invariance for sets and pair symmetry, then recompute P3, three-shape classification, pairwise same-root scores and all analyses using A\_r. Keep prior outputs as superseded analyses, not alternative independent tests.

Second, correct the primary inference table. Report the original conditional world bootstrap as stipulated by Part VIII, its conditional estimand, and the refitted label-exchangeability analysis as a distinct stress test. For the primary conclusion use a larger one-sided paired permutation evaluation for P2 and a paired refit-based gain assessment for P3. Recalculate Holm using the P2 \> 0.5 and ΔP3 \> 0 alternatives. Do not report the two separate classifier permutation p-values as a gain test.

Third, audit D0 versus NC0 against exact request hashes, seeds, temporal rank, elapsed time, output length and retry/stop state. The existing half-order diagnostic is inconclusive because one learner showed AUC 0.533. Any contextual source of the control discrepancy should qualify single-message structural interpretations and be checked against the set result as feasible.

Fourth, complete the missing secondary comparisons already specified: both five-relay-chain composition contrasts plus their three-class comparison, prompt-family H7 strata, and the promised Part V-A comparison of feature, embedding and boosted history predictors, with Brier score and per-class/event-type outputs. The actual five-configuration set predictor and derived pair probabilities should be reported separately from prompted-reader results. Clearly label any transfer comparisons that use different test rows as unpaired.

Fifth, use the reserved verification sample and challenge edits to validate the \*judge-v1\* instrument. Revise its judgment rubric so that fact-state and dispute-resolution outputs cannot contradict one another, and report natural and challenge performance separately. Recompute partial-access event opportunities, assess shared absence and “neither” ablations, and replace the constant-only null adjustment with a genuinely discriminating expected-overlap benchmark if an inherited-deviation explanation is to be advanced. If validation fails, keep the current no-anchored-claim rule. These tasks are necessary for mechanistic interpretation, not for publishing appropriately qualified text-only performance results.

No redesign of the shapes, prompt pools, world bank, producer assignment or replicates follows from this review. The remaining work is to align statistics and instrument semantics with the questions already posed.
