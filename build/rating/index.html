Disputes

Codebook (full rubric in validation/RUBRIC.md)

Stated: the report asserts the fact or an equivalent proposition, in any wording. Changed: the report refers to the same thing but asserts a contradicting value, person, place, time, cause, sequence, or polarity. Doubted: the fact's content with added uncertainty the record does not have, and no contradicting detail. Absent: the fact's content cannot be recovered. Precedence: changed, then doubted, then stated, then absent. For each dispute: first or second if the report gives only that account, both if it gives both, neither if it gives neither. Dispute codes must agree with the two member facts. Code what the report says, not what you think is true.
