Codebook

Preserved: the message states the fact with its meaning intact. Qualified: the fact appears but is hedged or attributed where the original was not. Altered: a value, time, entity, or polarity changed. Omitted: the fact does not appear. For each conflicting pair, record which member the message asserts, both, or neither. Code what the message says, not what you think is true.
